## html-playground — CodeRabbit review fixes (fixes) ✅

Addressed 4 CodeRabbit findings on the committed `html-playground.js` (commit `0bd31c5`). All verified via vitest (14/14), Playwright (2), smoke (0 errors), SPA perf (all ≤50ms), build, fallow, oxlint/oxfmt.

1. **Clipboard failure handling** — `shareCode` now guards `navigator.clipboard.writeText` (falls back to `Promise.reject` if API unavailable) and on `.catch()` shows a `.hp-share-link` readonly input prefilled with the URL + status "Copy blocked — copy the link manually". Verified happy path ("Share link copied") and rejection path (forced `writeText:()=>Promise.reject` → fallback input visible).
2. **CodeMirror addons now loaded** — config referenced `matchBrackets`, `autoCloseBrackets`, `extraKeys"Ctrl-Space":"autocomplete"` but the addons were never fetched (silently ignored). Added 5 script deps (`addon/edit/matchbrackets`, `closebrackets`, `matchtags`, `addon/hint/show-hint`, `anyword-hint`) + `show-hint.min.css` from the same jsDelivr CDN with computed SRI. Verified all 6 load 200 and `CM.commands.autocomplete` + `CM.hint.anyword` are functions.
3. **Listener isolated from user JS** — previously `buildScript` concatenated `LISTENER_SRC + userJs` into ONE blob, so a user syntax error prevented the whole script (incl. the error listener) from parsing → no error reporting. Now `renderPreview` emits TWO `<script>` tags in order: trusted `LISTENER_SRC` blob first, then user JS blob. Listener also now proxies `console.log/info/warn→info` and `console.error→error` to the console panel. Verified: `console.log` shows as info entry; a thrown error and a syntax error both report correctly.
4. **localStorage guarded** — `loadSavedState` wraps `localStorage.getItem` in try/catch (treats failure as empty saved state).

Key API change (tests updated): `buildScript(js)` now returns js as-is (was `js, listenerSrc`); `composeDocument` takes `scripts: []` array of blob URLs (was single `scriptSrc`/inline `js`) — emits one `<script src>` per entry.

Still KEEPING `sandbox="allow-scripts allow-same-origin"` (CodeRabbit flagged) — removing it makes the sandbox an opaque origin that cannot load parent-created blob: user scripts under CSP (CSP forbids `'unsafe-inline'` and blob: is only allowed in the parent). Risk mitigated by the trusted-listener isolation instead.

- oxlint: only the 2 pre-existing `container` contract-param warnings remain.
